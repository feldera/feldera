## Type probes

The Rust generator produces 84,224 deterministic scalar probes using the rule
documented in `sql-difftest/README.md`; CI generates and retains them. The Java
batch runner records verdict, diagnostics, schema and S2 at optimization level
zero. It explicitly distinguishes an internal compiler failure from an ordinary
SQL rejection. The initial matrix produced **59,456 acceptances, 24,768
rejections, including 1,384 compiler-bug cases**, and therefore failed its
oracle-readiness gate. No allow-list was added. Counts and build identities are
in [`evidence/type-probe-result.json`](evidence/type-probe-result.json).

One minimal reproduction is:

```sql
CREATE TABLE t(a BOOLEAN NOT NULL, b REAL NOT NULL);
CREATE VIEW v AS SELECT a = b AS result FROM t;
```

With assertions enabled, the original compiler fails in the pinned Calcite
`AbstractTypeCoercion.needToCast`, called by `TypeCoercionImpl.booleanEquality`.
The 1,384 cases comprise 160 Boolean/numeric equality assertions, 816
`INTERSECT ALL` type mismatches, and 408 `EXCEPT ALL` type mismatches.

`FelderaTypeCoercion` now repairs both paths. Calcite's implicit-cast mapping
omits Boolean inputs for floating-point and decimal targets even though its
equality coercion generates those casts. The adapter completes only the lenient
operand mapping; explicit CAST rules stay unchanged. This preserves the behavior
of the old compiler with assertions disabled. For set operations, the adapter
keeps the inferred column's nullability consistent with the CAST expression,
rather than copying nullability from the other input's wider type.

The corrected matrix passes with assertions enabled: **60,840 acceptances,
23,384 ordinary rejections, and zero compiler bugs**. Strict Rust validation also
passes. The result is in
[`evidence/type-probe-corrected.json`](evidence/type-probe-corrected.json).
CI now runs and validates the full scalar oracle, rather than only generating
its inputs. Runtime verification of all 60,840 accepted probes remains open.

A frozen pre-fix JAR, run without assertions to match production, accepted
59,616 probes and failed internally on 1,224 set operations. A full structural
comparison against the corrected run found **83,000 unchanged records** and
exactly those 1,224 failures becoming acceptances. No previously accepted query
or ordinary rejection changed verdict, schema, diagnostics, or canonical S2.
