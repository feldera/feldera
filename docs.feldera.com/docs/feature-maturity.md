# Feature maturity

Every feature in these docs is generally available unless its page says otherwise.

| Label | What it means |
|---|---|
| *(no label)* | **Generally available.** Proven in production at scale, across multiple deployments. Changes follow the normal release and deprecation process. |
| **Preview** | **Supported, and ready for production use.** Its configuration may still change between releases, and each change is listed in the [changelog](/changelog). |
| **Experimental** | **Available to use, not yet confirmed in production at scale.** Many community contributions start here. Its configuration can change in any release, without a deprecation period. |

## From Experimental to Preview

An Experimental feature moves to Preview when the Feldera team confirms that it works in production and we commit to support it. Community-contributed connectors and features often stay Experimental until we have this confirmation.

## From Preview to generally available

The bar for general availability is high. Multiple customers must run a Preview feature in production at scale, for an extended period.

Thus, many Preview features run in production for a long time before they become generally available.

If you use or plan to use a Preview or Experimental feature, tell us in the [Feldera Slack community](https://join.slack.com/t/felderacommunity/shared_invite/zt-3vf3n5dj5-HJuC1DFFY2wE1_AZUyNxqw) or through our [contact form](https://www.feldera.com/contact-us). Reports of production use help us promote a feature.
